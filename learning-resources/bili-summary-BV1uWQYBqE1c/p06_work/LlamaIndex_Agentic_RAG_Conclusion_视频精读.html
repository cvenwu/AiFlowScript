00:04 - 00:15

2. 课程能力回顾：从 Router Agent 到多文档 Agent

作者总结学习者在课程中学到的是 Agentic RAG，并按学习递进列出三层能力：

  • building a router agent：从构建路由代理开始，理解如何根据问题选择合适查询路径或检索策略。
  • tool calling：进一步引入工具调用，让 Agent 能根据任务调用外部工具，而不是只做静态检索。
  • building your own agent：最终构建自己的 Agent，使其不仅能围绕单个文档推理，还能跨多个文档推理。

这一段的核心结论是：Agentic RAG 的课程目标不是简单“检索 + 生成”，而是让 RAG 系统具备路由、工具调用和多文档推理能力。

00:15 - 00:25

3. 后续资源：自定义 Agent、社区模板与高级解析服务

画面切换到 Resources 页，作者给出三个继续深入的资源入口：

  • Custom agent：https://docs.llamaindex.ai/en/stable/examples/agent/custom_agent/，用于学习如何构建自定义 Agent。
  • Community-built Agents (LlamaHub)：https://llamahub.ai/?tab=agent，用于参考或提交社区构建的 Agent 模板。
  • Advanced document parsing with LlamaParse：https://cloud.llamaindex.ai/，用于利用更高级的文档解析服务处理复杂文档。

这里说明作者希望学习者在课程结束后继续沿着两个方向深化：一是 Agent 形态的扩展，二是 文档解析能力的增强。

核心内容复盘

  • 课程完成：作者确认学习者已经完成课程。

落地价值提炼

  1. 先复盘能力链路：确认自己是否已经理解 Router Agent、工具调用、多文档推理三层能力。
  2. 选一个真实场景试做：例如企业知识库、多文档问答、客服助手、资料解析助手。
  3. 优先补齐文档解析：如果资料包含 PDF、表格、扫描件或复杂版式，优先评估 LlamaParse 等解析服务。
