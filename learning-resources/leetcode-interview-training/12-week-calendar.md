# 12 周刷题日历

## 使用方式

- 每天按「当日题目 -> 复述 -> 记录」执行。
- 标记为「Go 复写」的题，先用 Python AC，再用 Go 复写核心逻辑。
- 周日不追求新题数量，优先完成错题二刷和 45 分钟模拟。
- 如果某天时间不足，保留 P0 题，分支题顺延到周六或周日。
